# FitTrack — Трекер тренировок

Учебный проект УП.01. Студент: Ахметов Максим.

## Возможности
- Главная панель со статистикой.
- Создание, просмотр, завершение и удаление тренировок.
- Справочник упражнений с группами мышц.
- Создание и удаление планов тренировок.
- Страница прогресса с аналитикой по месяцам.
- SQLite + Prisma для хранения данных.

## Требования
- Node.js 18.17 или новее (рекомендуется Node.js 20 LTS).
- npm.

## Установка и запуск (Windows)
1. Установить Node.js LTS с официального сайта https://nodejs.org/.
2. Распаковать архив проекта.
3. Открыть папку проекта в VS Code.
4. В терминале выполнить:

```bash
npm install
```

5. Создать файл `.env` в корне проекта и добавить:

```env
DATABASE_URL="file:./dev.db"
```

6. Создать таблицы SQLite:

```bash
npx prisma db push
```

7. Добавить демонстрационные записи:

```bash
npm run db:seed
```

8. Запустить приложение:

```bash
npm run dev
```

9. Открыть в браузере http://localhost:3000.

## Структура
- `src/app` — страницы, API-маршруты и глобальные стили.
- `src/components` — переиспользуемые компоненты интерфейса.
- `src/lib/prisma.ts` — подключение Prisma Client.
- `prisma/schema.prisma` — модели базы данных.
- `prisma/seed.ts` — начальные демонстрационные данные.

## Модели данных
- `Workout` — тренировка: название, дата, длительность, статус и заметки.
- `Exercise` — упражнение: название, группа мышц и описание.
- `WorkoutSet` — подходы: упражнение, число подходов, повторений и вес.
- `TrainingPlan` — план тренировок: название, описание и число дней в неделю.

## Примечания
Приложение работает локально, без регистрации и внешнего сервера. Не вводите реальные пароли, токены и персональные секреты. Демо-записи можно удалить и заменить собственными.


ВАЖНО: `package.json` находится непосредственно в корне архива. Откройте в VS Code папку, в которой одновременно видны `package.json`, `prisma` и `src`.

Быстрый запуск Windows: дважды щёлкните `УСТАНОВКА_И_ЗАПУСК.bat`. Установка пакетов требует доступа к интернету.
