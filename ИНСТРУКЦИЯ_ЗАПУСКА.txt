КАК ЗАПУСТИТЬ:
1. Установите Node.js 20 LTS.
2. Распакуйте архив(если нужно).
3. Откройте папку проекта в VS Code.
4. Откройте терминал в этой папке.
5. Выполните: npm install
6. При необходимости создайте в корне файл .env со строкой:
   DATABASE_URL="file:./dev.db"
7. Выполните: npx prisma db push
8. Выполните: npm run db:seed
9. Выполните: npm run dev
10. Откройте http://localhost:3000

Если команда не выполняется, проверьте установку Node.js командой:
node -v
npm -v

Для остановки сервера нажмите Ctrl+C в терминале.
